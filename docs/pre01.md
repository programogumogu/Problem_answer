# Cubic Number (easy)


問題文
=====
正の立方数 $X$ が与えられる。$\sqrt[3]{X}$ の値を求めよ。$T$ 個のテストケースが与えられるので、そのそれぞれについて答えること。

制約
-----
- $1 \leq T \leq 2 \times 10^5$
- $1 \leq X \leq 10^{18}$
- $X$ は立方数

入力
-----
入力はすべて整数である。
```
T
testcase_1
testcase_2
...
testcase_T
```

各テストケースは次のように与えられる。
```
X
```

出力
-----
各テストケースについて、$\sqrt[3]{X}$ の値を一行づつ出力せよ。


サンプル
=====
```入力1
1
27
```

```出力1
3
```
$27 = 3^3$ より、$3$ を出力してください。

```入力2
1
1000000000000000000
```

```出力2
1000000
```

$10^{18} = (10^6)^3$ より、$10^6$ を出力してください。


## 解説
制約より　$1 \leq \sqrt[3]{X} \leq 10^6$ なので、この範囲で3乗すると $X$ になるような値を二分探索で探せば良いです。時間計算量は $T\log{X}$ です。

### 追記
二分探索の基本問題です。
